# Contributing a version

Have a build we don't have? Here's how to submit it.

## Before submitting

Check the [Archive Downloader](https://none45.github.io/vortex-archive/archive-downloader/) "Available versions" list to confirm it isn't already archived.  
If you're unsure what version your file is, run it through the [Version Checker](https://none45.github.io/vortex-archive/version-checker/) first.

## Option 1: Open a GitHub Issue

Open an issue on this repo and include:
- Build type and version string (from the Version Checker)
- File size, and a hash (SHA-256) if available

A maintainer will follow up with where to send the file.

## Option 2: Contact none45 on Discord

You can also reach out to **none45** directly on Discord with the file/link and version details.

## What happens next

A maintainer verifies the version, usually by comparing it against the Version Checker output and a hash check, before adding it to the archive and making it available through the Archive Downloader.
