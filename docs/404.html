Vortex Archive Downloader

Pull a Vortex build from the archive, optionally wrapped in a launcher that bypasses the updater.

Requests go only to GitHub's API and a Cloudflare proxy, nothing else is contacted.

Vortex Version Checker

Pick a Vortex binary and it's scanned in your browser, never leaving your machine.

Click to choose a file, or drag one here
Scans the binary for update-guard markers and a version string
No network requests are made during the scan, all parsing happens client-side via FileReader.
